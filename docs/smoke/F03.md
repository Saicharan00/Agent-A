# F03 manual checks: app shell

Run `pnpm dev` in the sandbox and open http://localhost:3000 in your Windows browser.

1. Dark theme by default. Left sidebar: Agent A pinned at top, Bots / Groups (empty), Workspace links.
2. Click each Workspace link: the page title changes and the link is highlighted.
3. Top bar: click the sun/moon icon to switch to light. Reload: it stays light, with no dark flash.
4. Click the monitor icon (or press `Ctrl+\`): the Computer panel opens with Terminal · Desktop · Files · Runs tabs.
   Close it with the X.
5. Press `Ctrl+K`: the command palette opens. Type "tasks", press Enter to go to Tasks. `Esc` closes it.
6. `Ctrl+B` collapses/expands the sidebar; the choice survives a reload.
7. The "Runner: ok" pill is green. Stop the runner and it turns red within ~15 seconds.
