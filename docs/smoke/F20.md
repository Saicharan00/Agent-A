# F20 manual checks: Agent A delegation loop (real engines)

Uses real Claude Code / Codex runs, so it spends subscription usage. A small goal takes roughly 10–15 runs.
You need a lead bot (Agent A, `is_lead`) and at least two specialists. Until F21 seeds the team, make one bot the lead:
`sqlite3 data/agenta.db "update bots set is_lead = 1 where slug = '<slug>'"`.

1. `pnpm dev`, open Home. Under **New goal** write a small, non-confidential goal, e.g. "Write a one-page README for a
   CLI that converts CSV to JSON, plus a 20-line Python script that does it". Constraints: "Python standard library
   only". Leave **Auto-run** off and click **Start goal**.
2. You land in the goal's thread. Agent A restates the goal, lists assumptions/questions and proposes 2–4 tasks with
   acceptance criteria and a specialist for each, then asks you to confirm. The bar above says "Waiting for you to
   confirm the plan"; budget shows `runs 1/40`.
3. Optional: answer a question in the thread. Then click **Confirm plan**. Agent A creates the tasks (`create_task`
   tool cards); each one appears on `/tasks` and moves to In progress as its specialist starts in its task thread.
4. Open a task thread: the brief has the goal context and says to put artifacts in `/shared/projects/<goal-slug>/`.
   Check that folder in the Files tab after the hand-in.
5. When a specialist hands in, the goal thread shows "<bot> handed in "<task>" for review." and Agent A reviews it
   (`review_task`). If it requests changes, the specialist's task thread gets "Changes requested by Agent A: …" and a
   new turn. After 2 rounds of changes Agent A cannot send it back again: you get a notification and decide on the
   task board.
6. Click **Pause** while a task is queued: queued turns are cancelled, "Goal paused by the owner" appears, the
   composer's messages are refused ("is paused; resume it first"). **Resume** restarts the stalled tasks/reviews.
7. When every task is done the goal thread says "All N tasks are done…" and Agent A posts the goal report (what was
   done, decisions, risks/open questions, what you should do, 1–3 lessons). The bar and the Home card show **Done**
   at 100 %, and the decisions/lessons exist (`sqlite3 data/agenta.db "select title from decisions; select topic from lessons;"`).
8. Guardrails: start a goal with `maxRuns` low through the API
   (`curl -X POST localhost:3001/api/goals -H 'content-type: application/json' -d '{"goalMd":"…","autoRun":true,"maxRuns":3}'`):
   after 3 runs the thread says the goal "has used all 3 of its runs" and a "needs you" notification appears.
