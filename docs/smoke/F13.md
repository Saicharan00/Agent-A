# F13 manual checks: direct chat (session 1)

1. `pnpm dev`, open a bot's chat from the sidebar. An empty thread shows "Start a conversation with <bot>".
2. Type a message and press Ctrl+Enter (Enter adds a line). Your message appears at once on the right; the bot's turn
   appears under it with "Queued" or "Working…" and a typing indicator, and the reply streams in word by word.
3. Send something long-running, reload the page mid-reply: everything streamed so far is shown again and the reply
   keeps growing. Stop (in the composer or under the turn) ends it: the turn shows "Stopped".
4. When an engine hits its usage limit the turn shows "Usage limit reached — this turn runs again at HH:MM" and the
   automatic retry under it shows "Limited — resumes at HH:MM" (Cancel removes it).
5. Attach a file with the paperclip (or drop it on the composer): a chip shows the upload, the file appears in
   `data/bots/<id>/home/work/inbox/` (`/home/bot/work/inbox/` in the computer), the message lists `inbox/<name>` and
   the bot's prompt gets the full path. Files over 10 MB are refused.
6. Fenced code in a message is highlighted (both themes) and has a working Copy button.
7. Scroll up in a long thread: older messages load above without the view jumping.
