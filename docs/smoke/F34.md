# F34 — manual checks

1. **Windows launcher.** Double-click `scripts\windows\AgentA.cmd`. Expect an "Agent A" window running `pnpm launch`
   inside the sandbox (the sandbox starts first if it was stopped). Your browser opens http://localhost:3000 once
   the app answers. Run it again while the app is up: it opens the browser straight away.
2. **Stop.** Ctrl+C (or close) the "Agent A" window. http://localhost:3000 stops answering.
3. **README.** Skim Setup, Daily use and Troubleshooting. Anything wrong for your machine goes in HUMAN_TODO.
4. **Demo.** Follow `docs/DEMO.md` with the real engines (~15 minutes, about 6–12 runs).
