# F06 manual checks: engine authentication

Run these in a sandbox shell in the project folder (`sbx exec -it agent-a bash`, then `cd` to the project).
Prereqs: `pnpm image:build` done; the domains in HUMAN_TODO 12 allowed.

1. **Claude:** `pnpm auth:claude` → open the printed link, approve, paste the code back into the terminal.
   When asked, paste the printed token (input is hidden). It is saved to `.env.local` as `CLAUDE_CODE_OAUTH_TOKEN`.
2. **Codex:** `pnpm auth:codex` → open the link, enter the device code. The login is saved to
   `data/secrets/codex/auth.json`; `ls -l data/secrets/codex` shows `-rw-------`.
3. `pnpm dev`, open http://localhost:3000/settings → Engines: both cards say **configured**; top bar shows
   `Claude: ready`, `Codex: ready`.
4. Start a bot computer (`curl -s -X POST localhost:3001/api/bots/<id>/computer/start`), then press **Re-check**:
   both cards say "CLI confirms the login".
5. Leak checks: `docker inspect <container> --format '{{json .Config.Env}}'` contains no `CLAUDE_CODE_OAUTH_TOKEN`;
   the `pnpm dev` output contains no `sk-ant-`.
6. One real prompt per engine (uses a little of your plan): `SMOKE=1 pnpm smoke:auth` → 2 passed.
7. Fallback (optional): with the token removed from .env.local, a bot's own `claude` /login (F14 terminal) shows the
   card as "Per-bot terminal login".
