# F11 manual checks: live updates

1. `pnpm dev`, open http://localhost:3000. In the browser dev tools (Network → WS) there is one `/ws` connection;
   its messages show `subscribed` for `global` and a `ping` every 20 s.
2. Restart only the runner (save any file under `apps/runner/src`; `tsx watch` restarts it): the `/ws` connection
   reconnects by itself within a few seconds and re-subscribes; no page reload is needed.
3. Usage-limit pill (mock): start with `AGENTA_ENGINE_OVERRIDE=mock pnpm dev`. A "Mock: on" pill appears. Queue a
   `[mock:limit]` run (until the chat arrives in F13: `pnpm db:seed`, then insert a queued run for the Echo Bot with
   prompt `[mock:limit]`, e.g. with the snippet in `tests/e2e/live.spec.ts`). Within ~5 s, without reloading, the
   pill reads "Mock: limited until HH:MM" (amber); two minutes later the retry runs.
4. Docker pill: with the app open, stop the sandbox's Docker daemon (or wait for it to be unavailable): the pill turns
   "Docker: down" within ~10 s without a reload, and back to "ok" when it returns.
5. Opening `ws://localhost:3000/ws` from another site is refused (403): only the app's own origin may connect. If you
   reach the app under another host name or port, set `AGENTA_WEB_ORIGIN` for the runner accordingly.
