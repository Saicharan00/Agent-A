# F05 manual checks: bot computers

Prereq: `pnpm image:build` done. Stop any running `pnpm dev`, then in the sandbox:

1. `pnpm --filter @agenta/runner start`, and in a second shell `curl -s localhost:3001/api/health`:
   `"docker":{"ok":true,"version":"…","image":true}`.
2. Find a bot id: `sqlite3 data/agenta.db "select id,name from bots"` (the seeded Echo Bot).
3. `curl -s -X POST localhost:3001/api/bots/<id>/computer/start`: after ~5–20 s returns `"status":"running"`,
   `"health":"healthy"` and a `novncPort`. `curl -s localhost:<novncPort>/vnc.html | head -3` shows HTML.
4. `docker ps --filter label=agenta=1`: `agenta-bot-echo-bot`, port `127.0.0.1:<port>->6080/tcp` (never 0.0.0.0).
5. Stop the runner (Ctrl+C) and start it again: the log shows `containers reconciled` with the bot `adopted`.
6. `curl -s -X POST localhost:3001/api/bots/<id>/computer/reset -H 'content-type: application/json' -d '{"wipeHome":true}'`
   → `confirm_required`. With `"confirm":true` the home is erased (don't do this on a bot you care about).
7. `curl -s -X POST localhost:3001/api/bots/<id>/computer/stop` → `"status":"stopped"`.
8. Real-Docker test suite: `pnpm test:docker` (about 1–2 minutes).
