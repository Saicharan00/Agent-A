# F12 manual checks: bot management

1. `pnpm dev`, open http://localhost:3000/bots/new. Submit empty: "Name is required" appears and the Name field is
   focused. Fill name, role, pick Codex + a model, a colour and the hexagon shape, write instructions and switch to
   Preview (headings render). Create: you land on the bot page and the bot appears in the sidebar under Bots.
2. `/bots` shows a card with avatar, role, engine badge, computer status and last activity. Chat opens the DM thread
   (chat itself arrives in F13), Computer opens the right panel with that bot in focus.
3. Change RAM while the computer is running: saving shows "Resource limits apply after the computer restarts".
   Stop the computer and save another RAM change: `docker ps -a --filter label=agenta.bot=<id>` shows no container
   until the next start, which recreates it with the new limit.
4. `docker exec -u bot <container> ls -l /home/bot/.agenta/mcp-token` shows `-rw-------`; the DB has only the hash
   (`sqlite3 data/agenta.db "select mcp_token_hash from bots"`).
5. Archive: the computer stops, the bot leaves the sidebar and appears under Bots → Archived. Restore brings it back.
6. Delete…: the button stays disabled until the exact name is typed. With "Also delete its home folder" ticked,
   `data/bots/<id>` is gone afterwards; unticked, it stays. The container is removed either way.
