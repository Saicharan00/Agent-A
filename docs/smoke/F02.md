# F02 manual checks — database

Run inside the sandbox from the project folder.

1. `pnpm db:seed` → prints `seeded …/data/agenta.db: Echo Bot (bot_…), DM thr_…`. Run it again → `already seeded`.
2. `sqlite3 data/agenta.db ".tables"` → lists 20 app tables plus `__drizzle_migrations`.
3. `sqlite3 data/agenta.db "select name, engine from bots"` → `Echo Bot|mock`.
4. `pnpm dev` → the runner log shows `database ready` with the DB path. Migrations apply automatically on start.
5. Optional, to use a different DB: set `AGENTA_DB_PATH=data/other.db` in `.env.local`.
