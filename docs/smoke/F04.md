# F04 manual checks: bot computer image

All commands run inside the sandbox.

1. `pnpm image:build` ends with `Built agenta-bot:latest (= agenta-bot:<sha>) in …s, size …`.
2. `docker run --rm agenta-bot:latest bash -lc "whoami && claude --version && codex --version && gh --version && python3 --version && npx playwright --version"`
   prints `bot` and a version for each tool.
3. `docker run -d --rm --name agenta-try --label agenta=1 -p 127.0.0.1:16080:6080 agenta-bot:latest`, wait ~5 s, then
   `curl -s localhost:16080/vnc.html | head -3` shows HTML, and after ~20 s
   `docker inspect -f '{{.State.Health.Status}}' agenta-try` says `healthy`.
4. Watch a headed browser: `docker exec agenta-try bash -c 'cd /tmp && node -e "require(\"/usr/local/lib/node_modules/playwright\").chromium.launch({headless:false}).then(async b=>{const p=await b.newPage();await p.goto(\"about:blank\");await new Promise(r=>setTimeout(r,15000));await b.close()})"' &`
   (Viewing the desktop from Windows needs the noVNC port published to the host; the UI for it arrives in F16.)
5. Clean up: `docker rm -f agenta-try`.
