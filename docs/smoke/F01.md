# F01 manual check — scaffold

1. In the sandbox: `pnpm dev`.
2. On Windows, open http://localhost:3000. You should see the "Agent A" heading and a green "Runner: ok" badge.
   - If the page doesn't load, add `AGENTA_WEB_HOST=0.0.0.0` to `.env.local` and restart `pnpm dev` (HUMAN_TODO item 9).
3. `pnpm run doctor` prints node, pnpm and docker versions.
